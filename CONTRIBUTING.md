# Cum contribui

Mulțumim că ajuți! Orice contribuție mică contează: o corectură, o lecție, un bug raportat.

## Flux

1. Alege un issue (sau deschide unul) și spune în comentariu că îl faci.
2. Fă fork și creează un branch: `git switch -c fix/titlu-scurt`.
3. Fă modificarea mică și rulează `npm run check` și `npm run build`.
4. Commit cu mesaj clar, push, apoi deschide un pull request cu șablonul completat.
5. Un owner din zona respectivă verifică PR-ul. Răspunde la comentarii în același PR.

Lecția „Primul tău Pull Request” din catalog explică pașii.

## Reguli

- PR-uri mici, o singură idee.
- Fără date inventate (statistici, mentori, citate).
- Conținut propriu sau cu licență clară; nu copia de pe alte site-uri.
- Texte în română cu diacritice; interfața are și variantă în engleză (`src/i18n/ui.ts`).
- Verifică în light și dark, pe desktop și mobil.
